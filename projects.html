PACE — Personalized Academic Calendar and Events

SHEET 01 — In progress

PACE queries fragmented campus data — timetables, notices, event listings — through a single backend REST API. Rather than reaching for an orchestration framework like LangChain, I architected the FastAPI service to handle request and response logic directly, keeping full control over how retrieval and generation are wired together.

The retrieval layer is a bare-metal RAG pipeline: the Gemini API produces embeddings, and similarity search runs as raw SQL against pgvector using cosine similarity — no vector-database abstraction sitting in between.

  • FastAPI
  • PostgreSQL
  • pgvector
  • Gemini API
  • Python

Thodar

SHEET 02 — VIT Hackathon, Finalist

Thodar is a healthcare logistics platform concept addressing gaps in last-mile medical supply coordination — getting the right supplies to clinics that need them, when they need them. I conceptualized and pitched the idea as a Finalist entry at the VIT Hackathon.

With hackathon time constraints in play, I used rapid AI-assisted prototyping — Lovable for the interface scaffold, React for the working layer — to get a functioning concept in front of judges fast enough to validate the idea rather than just describe it.

  • Lovable
  • Rapid Prototyping
