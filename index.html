How I work

Direct over abstracted

I'd rather write a request/response pipeline by hand than take on the weight of an orchestration framework I don't fully control. Understanding beats convenience.

Data structures first

Before reaching for a library, I ask what the underlying query actually needs — raw SQL and pgvector over a black-box vector store, where it makes sense.

Ship under constraints

Hackathon time limits and coursework deadlines have taught me to validate an idea fast, then go back and build it properly.
